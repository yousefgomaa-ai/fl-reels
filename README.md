# Two Paths

قناة يوتيوب Shorts بالستيك مان: شخصين قدام نفس الموقف، واحد بيتحرك والتاني بيتردد، والريل بينتهي بجملة.
مشروع منفصل عن fl-reels.

## المجلدات
- `stick/`: سكربتات الريلز (Python + Pillow + numpy + ffmpeg) والفيديوهات اللي طلعت منها
  - `bg/`: خلفيات حقيقية متولدة، تتحط ورا الرسم (BG_PHOTO, BG_BLUR, BG_DIM)
  - `avatar/`: صور القناة والبانر (2560x1440)
  - `styles/`: تجارب الستايل
- `study/`: الريلز المرجعية الـ٧ وبيانات القناة اللي درسناها

## تشغيل ريل
```
cd stick && python3 motivation_bus.py
```

## الوصفة
1. فكرة في سطر: نفس الموقف، تصرفين عكس بعض
2. رمز واحد ملموس (صناديق، حجر، مية...)
3. عداد بيتحرك (أيام، مرات، مسافة)
4. مفاجأة في الآخر
5. جملة ختام سطرين، الضربة في التاني
6. من 13 لـ16 ثانية وبتلف على نفسها
